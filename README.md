Linguistische, inhaltliche Analyse im Rahmen der Diss-Publikation „Mama liebt ihr Baby“ – Linguistische Studien zur Vermenschlichung von Haustieren im sozialen Netzwerk Instagram".

- Analyse von 796 Instagram-Captions mit dem Ziel, den Status von Hunden auf Instagram zu untersuchen, wie diese sprachlich konstruiert werden und ob sie als (menschliche) Familienmitglieder behandelt werden.
- Erstellung eines Python-Skripts, das die API von OpenAI ChatGPT-4 nutzt.
- ChatGPT hat Zugriff auf die Bildbeschreibungen.
- Im Prompt sind relevante Anweisungen enthalten, wie die einzelnen Captions zu analysieren sind.
- Ziel: Hervorhebung relevanter thematischer Aspekte, die in der (Instagram-)Narrative vorkommen.

_Dissertationsprojekt von Sara Goffredo, Doktorandin in Deutscher Linguistik an der Universität Zürich. Die Publikation wurde eingereicht._
